# Security Policy

## Reporting a Vulnerability

If you discover a security issue:
1. **Email the maintainer directly** (`nils.steenebruegge@volteuropa.org`) — do not open a public issue.
2. Describe the vulnerability, affected components, and reproduction steps.
3. Allow 72 hours for initial triage and coordinated response.

## Dependencies & Scanning

- Automated dependency updates via Dependabot.
- Static secret analysis via Gitleaks in CI.
- Supply chain security verified with OpenSSF Scorecard.
